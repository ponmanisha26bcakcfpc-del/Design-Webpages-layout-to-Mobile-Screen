🎓 Student Attendance App – High-Fidelity Design Points
1. ✨ Project Overview
A Student Attendance App designed using Figma with a modern, colorful, and user-friendly interface. Students can view their attendance percentage, present days, absent days, and subject-wise attendance.

2. 🎯 Objective
- Track student attendance easily.
- Display attendance percentage clearly.
- Provide quick access to student records.
- Create a responsive desktop and mobile interface.
